About me

A CSE student who enjoys taking software apart to see where it fails.

I am Abir Hasan, a Computer Science and Engineering student at Daffodil International University, based in Dhaka.

My interest is software quality. I like breaking a feature down into what it should do, writing test cases for it, and tracking down the root cause when something fails.

I have practised manual testing on real websites, written test case documents from requirements, tested APIs with Postman and Newman, and managed work in Jira. I also build web and AI projects, which teaches me how developers think and where bugs usually hide.

I am now looking for a QA internship where I can apply manual testing, API testing and project management in a real team, and help ship software that works the way users expect.
